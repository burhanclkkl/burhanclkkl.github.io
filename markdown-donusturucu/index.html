Markdown’a doğrudan çevir.

Ücretsiz Türkçe Markdown dönüştürücü: yapıştır, düzenle, kopyala veya indir.

Markdown dönüştürücü nedir?

Markdown dönüştürücü, düz metni başlık, liste ve kod blokları gibi Markdown yapılarıyla düzenlemeye yardımcı olan bir araçtır. Bu sayfa metnini tarayıcıda kurallarla işler; cümlelerini yeniden yazmaz.

Metni Markdown’a nasıl çeviririm?

Metnini sol alana yapıştır. Yazdıkça sağdaki Markdown çıktısı yenilenir. Çıktıyı düzenleyebilir, Önizleme ile kontrol edebilir, Kopyala veya .md indir düğmesini kullanabilirsin. Dar ekranlarda Metin, Markdown ve Önizleme sekmeleri arasında geçiş yap.

Neler otomatik düzenlenir?

Kısa ve ayrı duran ilk satır ana başlık; iki nokta ile biten kısa bölüm adları alt başlık; • ve benzeri madde işaretleri liste olarak önerilir. Geçerli Markdown işaretleri ve kod bloklarının içi korunur. Belirsiz bir satırın anlamı kesin olarak çıkarılamaz; son düzeltme sende.

Notlarım kaydediliyor mu?

Notların bu sekmede işlenir; bir sunucuya gönderilmez veya otomatik kaydedilmez. Sayfayı kapatmadan önce çıktını kopyala ya da indir. Önizleme dış görselleri yüklemek yerine alternatif metin ve adresini gösterir.

Bu araç ücretsiz mi?

Evet. Markdown dönüştürücü ücretsizdir; hesap veya API anahtarı gerektirmez. Kullanmak için tarayıcında JavaScript açık olmalıdır.

Markdown yazımını nereden öğrenebilirim?

Markdown Atölyesi’nde başlık, kalın yazı, liste, bağlantı, kod bloğu, alıntı ve tablolar için kod ile görünen sonucu yan yana inceleyebilirsin.
